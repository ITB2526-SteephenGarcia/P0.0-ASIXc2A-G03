# Scripts auxiliares

Esta carpeta contiene scripts auxiliares preparados para facilitar comprobaciones repetitivas.

## Importante

Estos scripts no se presentan como evidencia de que fueran utilizados durante todo el despliegue original.

Su función es ayudar en la fase de validación final y mantenimiento.

## Archivos

- [comprobaciones_linux.sh](./comprobaciones_linux.sh)  
  Ejecuta comprobaciones de solo lectura sobre red, rutas, DNS y acceso básico a los servicios principales.

Las pruebas definitivas deben documentarse con sus resultados reales y capturas cuando corresponda.
